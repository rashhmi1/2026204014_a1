\# Student Portal



Project Overview



Student portal is the C++ application created for the Git and GitHub lab assignment.

The main purpose of the assignment is to learn and practice Git version control, branching, merging, stashing, conflict resolution, and history recovery.



\## Current Features



The current application includes:



\- A welcome message is displayed when the program starts.

\- A greeting for the developer.

\- Addition of two integer values.

\- Calculated sum is displayed.

\- A completion message after execution.
